# syretaBrowser – Setups

Hier liegen nur die Setups (MSI) von **syretaBrowser** (syreta). Der Code ist nicht öffentlich.

- Installieren: in der neuesten Release `syretaBrowser-<Version>-x64.msi` herunterladen und starten.
- Updates: installierte syretaBrowser suchen hier selbst nach neuen Versionen (`syretabrowser-update.json`) und installieren sie beim Beenden.
